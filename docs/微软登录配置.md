## Entra 端设置

选择用户的 TORA 注册应用，支持个人 Microsoft 账户。在“身份验证”添加“移动和桌面应用程序”，注册 `http://localhost/auth`（localhost 端口可动态变化）；允许公共客户端流。桌面不需要 Client Secret。

初次设备码接口探测返回 `AADSTS70002`。用户启用移动/桌面公共客户端并保存后，复测返回 HTTP 200，设备码有效期 900 秒；真实开发应用也已生成设备码，并进入等待用户授权状态。

## 一键设备码界面

选择微软验证服务时不显示账号/密码输入框，也不要求输入邮箱。点击“生成设备码并登录”直接提交空账号和设备码模式；设备码返回后显示只读代码与复制按钮，先通过原生剪贴板接口自动复制，再打开微软验证页。等待期间保留代码和复制按钮，主按钮显示等待状态，取消操作单独提供。其他验证服务仍使用原有输入与校验。

真实开发窗口已观察：没有微软账号输入框；设备码生成、手动复制入口与自动复制成功提示均可见；微软验证页自动打开，并由用户完成授权。Minecraft API 的应用审核限制仍独立存在。
