# TORA Minecraft Launcher · 参考与设计规范

参考查阅日：**2026-10-23**  
文档性质：设计输入与拟实施规范。本文不代表所列功能已经完成、连接真实服务或通过运行验证。

## 1. 产品方向

TORA 是以实例为中心的 Minecraft 桌面启动器。使用中文界面，优先服务“找到实例 → 查看运行环境 → 启动游戏”和“创建实例 → 安装内容 → 返回游戏”的连续操作。

视觉主参考为 XMCL，功能组织与前后端分层参考 VersePC2，HMCL、PCL、PCL-CE 用于补充启动器的成熟使用流程。产品归类为桌面工具，而非营销落地页：主操作应直接可见，信息密度适合长时间管理多个实例。

本规范采用用户指定的 `premium-visual-reference-library` 与 `ui-design-system` 工作方式：从指定来源提取可解释的模式，再形成 TORA 自己的布局、设计令牌和组件状态。下文的具体颜色、尺寸和动效时长都是 TORA 的设计决定，不是对上游原始参数的测量结果。

## 5. 结构原则

界面、应用服务与原生能力分层，借鉴 VersePC2 的 Web 前端/原生后端边界及 XMCL 的 UI/API/Runtime 边界。项目选用 **Electron + Vue 3 + `@xmcl/core` / `@xmcl/installer`**；按 Verse 的功能组织独立实现，不直接引入 Verse 的 GPL 源码。选用依赖及目录结构属于实施决定，不代表对应功能已经运行通过。

| 层 | 职责 | 不应承担的职责 |
| --- | --- | --- |
| 页面与组件 | 渲染状态、收集输入、导航、展示反馈 | 直接拼装敏感启动参数、直接读写任意文件路径 |
| 应用服务 | 实例、账号、安装、资源、任务和日志的稳定接口 | 把具体 UI 组件状态当成持久数据 |
| 原生或运行时适配 | 文件系统、Java 探测、下载、进程、凭据保存 | 只用定时器模拟真实任务完成 |
| 持久层 | 实例配置、设置、任务结果与经过处理的日志 | 明文记录 access token、refresh token 或完整敏感命令行 |

浏览器预览可以使用明确标记的演示数据；真实桌面模式必须以实际文件、网络请求、授权和子进程结果为依据。两个模式的差异应体现在能力与状态中，避免点击“启动”后仅弹出成功提示。

## 6. 视觉规范

### 布局与信息密度

- 使用深炭灰底色和薄荷绿强调色。强调色主要服务选中状态、主操作与成功反馈。
- 桌面采用紧凑侧栏和宽实例工作区。标准侧栏建议 216px；紧凑模式建议 72px；主体保留 24–32px 边距。
- 标准窗口目标为 1280×800，另检查 1440×900、1024×768 和 900×640；这些是设计与检查目标，不是已经验证的结果。
- 首页允许一个宽幅实例区域承载背景、版本和启动操作；下方以紧凑实例列表、资源入口与任务摘要补足工作流。不要用大量同权重卡片分散启动焦点。
- 顶部区域展示当前位置与必要工具。页面标题、筛选栏、主内容的顺序保持稳定，跨页保留当前实例上下文。
- 右侧辅助区只在信息有价值且宽度足够时出现；窄窗口移到内容后方，不强行压缩主要列表。

### 设计令牌

| 令牌 | 建议值 | 用途 |
| --- | --- | --- |
| `color.background` | `#101516` | 应用背景 |
| `color.surface` | `#171E20` | 侧栏、列表和主要面板 |
| `color.surfaceRaised` | `#1E282B` | 弹层、悬停和局部高层表面 |
| `color.border` | `#2C3A3D` | 低对比装饰分隔；不能单独承担焦点或关键状态 |
| `color.text` | `#EDF5F2` | 主要文字 |
| `color.textMuted` | `#92A5A7` | 次要说明与路径 |
| `color.accent` | `#6EE7B7` | 主操作、选中标记、成功 |
| `color.onAccent` | `#102319` | 薄荷绿按钮上的文字 |
| `color.warning` | `#F5C777` | 兼容性和需关注事项 |
| `color.error` | `#FF9898` | 失败与危险操作提示 |
| `space` | `4 / 8 / 16 / 24 / 32 / 48px` | 以 8px 为主，4px 用于图标及文字微调 |
| `radius.control` | `10px` | 按钮、输入与菜单项 |
| `radius.panel` | `14px` | 实例面板、弹窗与卡片 |
| `shadow.popover` | `0 16px 48px rgba(0,0,0,.28)` | 仅用于浮层层级，不给每个容器添加重阴影 |

圆角、间距和颜色集中定义，再映射到组件；不要为每个页面临时新增接近的值。边框颜色较淡，只用于装饰分隔；可交互轮廓、焦点和状态应有更明确的视觉反馈。

### 文字与图标

- 使用本机系统无衬线字体，中文优先系统中文字体；建议字体栈为 `Inter, -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`，未安装 Inter 时正常回退。
- 页面标题建议 28–32px / 600，分区标题 18–20px / 600，正文 14px / 400，控件 13–14px / 500，辅助信息 12px / 400。
- 主内容不使用大段英文装饰标题。Minecraft、Fabric、NeoForge、Java 等产品与技术名称保留准确拼写。
- 日志、版本号和运行参数可使用等宽字体。时间、文件大小与下载速度对齐，避免数值变化导致布局抖动。
- 图标选用同一套线性图标，常用尺寸 18–20px。只含图标的按钮必须有可访问名称，悬停提示不替代按钮名称。

### 图片与动效

- 实例背景作为游戏氛围与实例识别的辅助，不覆盖操作区。文字区域使用稳定遮罩，并检查窄窗口裁切。
- 实例图标、资源缩略图和背景分别定义比例；加载失败时使用简洁占位，不显示浏览器损坏图片图标。
- 不把上游截图直接当成 TORA 的界面成果。使用第三方视觉素材时记录来源及授权条件。
- 悬停与状态过渡建议 120–180ms，面板切换建议 180–240ms，优先使用透明度和轻微位移。
- 尊重系统减少动态效果偏好；关闭装饰性动效后仍能理解加载、完成和失败状态。

## 7. 核心组件与状态

| 组件 | 需要覆盖的状态 | 交互要求 |
| --- | --- | --- |
| 侧栏导航 | 默认、悬停、当前、键盘焦点、紧凑 | 当前项以背景、图标/文字和位置标记共同表示；返回页面保留合理上下文 |
| 实例卡片/列表行 | 未选中、选中、收藏、启动中、运行中、不可用 | 选中与启动动作分开；操作区不因状态变化产生明显跳动 |
| 启动按钮 | 可启动、准备中、运行中、需修复、不可用 | 文案说明真实下一步；不可用时解释原因；防止重复提交 |
| 资源条目 | 加载、可安装、已安装、不兼容、失败 | 版本与加载器条件靠近安装按钮，不能仅用颜色表达兼容性 |
| 任务行 | 排队、执行、暂停、取消、失败、完成 | 阶段与总进度区分；缺少总量时使用不定进度，不伪造百分比 |
| 表单控件 | 空、填写、校验失败、保存中、已保存 | 标签常驻；错误靠近字段；失败不清空用户输入 |
| 弹窗 | 打开、处理中、错误、完成 | 打开时移动焦点，关闭后返回触发控件；Esc 行为与操作状态一致 |
| 空状态 | 无实例、无结果、无账号、无任务 | 一句话解释原因，并给出与当前场景相关的下一步 |
| 错误提示 | 网络、权限、文件缺失、Java 不兼容、授权失败 | 明确受影响对象，保留重试、查看日志或调整设置入口 |

## 8. 响应式与可访问性

- 1200px 以上使用完整导航和宽工作区；900–1199px 收紧辅助区；更窄宽度采用紧凑导航并将多列内容折为单列。实际断点由内容是否拥挤决定。
- 核心桌面任务在 900×640 下仍应可达；弹窗高度受视口限制，内容滚动时主要操作可访问。
- 键盘可以完成导航、实例选择、表单提交和弹窗关闭；焦点样式始终可见。
- 不只靠薄荷绿、黄、红区别状态，同时提供文字或图标说明。
- 普通文字目标对比度至少 4.5:1；大字和必要非文字界面元素按适用要求检查。实际组件、图片背景与禁用状态需要渲染后复核。
- 图标点击目标建议至少 32×32px，主要按钮建议 40–44px 高；需要触控使用的控件扩大命中区。

## 9. 实施与验证记录要求

实现过程中应把“页面可交互”“数据已持久保存”“真实服务可用”“游戏进程已启动”分别记录。视觉截图不能替代启动链路验证，成功编译也不能替代实际界面验收。

后续验证至少覆盖：

1. 新建、选择、重命名实例，刷新或重启后状态一致。
2. 修改 Java、内存和目录，实际启动参数与选择一致。
3. 安装任务经历开始、进度、失败/取消和成功时，界面与任务结果一致。
4. 登录状态来源真实；凭据不出现在普通日志或导出报告中。
5. 资源筛选与当前实例版本相符，安装前能看到所需依赖。
6. 启动失败能找到日志与下一步；启动成功有进程或游戏窗口证据。
7. 所需窗口尺寸下无主操作遮挡，长名称、长路径和空列表可正常显示。
8. 键盘焦点、减少动态效果及文字对比度在实际界面中检查。
