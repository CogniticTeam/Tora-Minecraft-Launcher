# 以下为已归档的历史方案（2026-10-23，已撤回）

# TORA 独立界面设计规范

2026-10-23。用户最新要求：重新设计界面，保持与当前 XMCL 相近的视觉质感、动画表现；所有文字使用系统字体。该要求替代此前的 UI 1:1 复刻目标。

## 设计方向

以游戏空间为中心的桌面工作区。左侧带文字的导航与游戏列表，右侧当前游戏、可操作的启动检查、内容管理与启动操作。避免沿用 XMCL 的图标轨道、底角启动胶囊和悬浮内容卡片组合。

- 基础色：纸白 #F4F6FA、面板白 #FFFFFF、正文 #162032、次要文字 #697386、蓝 #3388C9、状态绿 #3A9A7D。用户主题色和明暗模式继续生效。
- 字体：system-ui、macOS 系统字体、Segoe UI、中文系统字体；代码使用系统等宽字体。图标使用有来源的图形资源，不作为文字字体。
- 布局：宽 204px 的文字导航；内容区最大宽 1440px；常用操作按游戏、内容、启动三层组织。800×400 时导航收为 72px，并保证内容可滚动。
- 材质：半透明表面、细边框、柔和分层阴影、背景模糊。背景模糊只用于导航和浮层，避免全屏多层叠加。
- 动效：点击反馈 100ms，导航/悬停 180ms，内容进入与浮层 240ms，统一 cubic-bezier(.2,.8,.2,1)。位移限 6–10px；尊重减少动态效果设置。

## 参考与复用边界

主要参考为 Voxelum/x-minecraft-launcher 的当前源码及运行界面：关注透明度层次、菜单展开、卡片反馈和切换节奏。独立编写 TORA 导航、首页结构、品牌图形和启动控件。不上架 XMCL 的名称、标志或第三方赞助资质；原始开源代码的版权、MIT 许可和来源继续保留。

许可是代码复用依据，不是对所有商标、素材或最终产品的法律保证。未取得许可的第三方品牌素材不作为 TORA 自有资产。
