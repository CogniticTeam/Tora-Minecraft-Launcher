# TORA：XMCL 上游复用与运行时隔离

记录日期：**2026-10-23**。

## 来源与当前路线

当前实现使用 [Voxelum/x-minecraft-launcher](https://github.com/Voxelum/x-minecraft-launcher) 的完整源码，位于项目的 `xmcl/` 目录。按用户要求保留 XMCL 原有界面结构与交互，在此基础上更换 TORA 品牌并隔离运行环境。这是基于 XMCL 的衍生版本，不再是此前仅借鉴布局、单独调用 npm 启动库的实现。

本次读取的源码根 `package.json` 版本为 `0.72.0`；本地源码目录不带 `.git`，此版本号不能当作精确 Git 提交标识。源码来源以原 GitHub 仓库为准。

## 运行时改动清单

下表路径均相对 `xmcl/xmcl-runtime/`。

| 文件 | 具体改动 | 影响 |
| --- | --- | --- |
| `constant.ts` | `LAUNCHER_NAME` 改为 `tora-minecraft-launcher`；新增默认游戏目录 `.tora-minecraft`；默认使用用户注册的 TORA Client ID，并允许 `TORA_MICROSOFT_CLIENT_ID` 显式覆盖 | TORA 的配置目录与 XMCL 分离；没有内置上游 Client ID 作为回退 |

| `settings/pluginSettings.ts` | 初始化、加载及保存时强制 `disableTelemetry=true`，界面尝试开启也会恢复为关闭 | 遥测开关不能重新连接原上游出口 |
| `user/pluginOfficialUserApi.ts` | Microsoft 游戏登录使用 TORA 环境变量；Xbox 设备凭据使用 TORA namespace；OAuth 回调仅使用本机 localhost | 不沿用 XMCL 注册应用；不通过 XMCL 网站中转该登录回调 |
| `user/accountSystems/MicrosoftOAuthClient.ts` | 未配置 Client ID 或配置成上游原 Client ID 时，在读取凭据或网络请求前报错；MSAL 缓存与临时原生运行目录改为 TORA 名称 | 现有界面会收到明确中文错误；需要配置自有应用才能登录；已有 XMCL OAuth 缓存不复用 |

| `xmclAccount/XmclAccountService.ts` | 账号服务的 Microsoft 授权入口同样使用 TORA 环境变量；会话与设备密钥 service 名改为 TORA | 第二个 Microsoft 入口也没有上游 Client ID 回退 |

内部 `xmcl://` 服务路由、资源 URL、包名及接口名保留，以避免破坏原界面与主进程之间的协议。它们与操作系统注册的外部深链不是同一职责。Electron 的产品名、系统 `userData` 和 `tora-minecraft://` 外部协议由桌面壳层单独处理。

## 数据目录行为

运行时应用配置目录为 `host.getPath('appData')/tora-minecraft-launcher`。macOS 常规环境下对应 `~/Library/Application Support/tora-minecraft-launcher`；实际路径以启动日志为准。首次设置建议的游戏目录为 `~/.tora-minecraft`。

运行时不会自动读取原 `appData/xmcl/root`、复制原账号或迁移 `~/.minecraftx`。首次运行应选择 TORA 独立目录。用户主动选择或导入其他游戏目录是后续显式操作，不属于自动迁移。

## Microsoft 登录配置

已接入用户提供的 TORA Microsoft 公共客户端 `1710c023-af88-403a-bcc3-59e0dda23f09`。桌面应用默认使用此 ID，双击打开无需设置环境变量。部署其他已获准应用时可覆盖：

```bash
export TORA_MICROSOFT_CLIENT_ID='自己注册的应用客户端ID'
```

修改后重启主进程。未设置环境变量时使用 TORA 已注册的 ID，不会使用 XMCL 的 Client ID。该值是应用标识，不是 Client Secret，启动器不应接收或保存 Client Secret。

真实 Microsoft/Xbox/Minecraft 授权尚需用注册完成的 TORA 应用及有效账号验收。配置存在或单元测试通过，不等同于真实账号登录成功。
